# ビンボーマップ (Binbo Map) 🍜

한국의 **거지맵**을 일본 시장에 맞게 로컬라이징한 서비스입니다.

> 컨셉: **"1000円以下のコスパ最強スポットをみんなで共有"**
> 타겟: 외식 비용이 부담되는 일본 20대 대학생

## 저장소 구조

| 경로 | 내용 |
|---|---|
| [`mobile/`](mobile/) | **메인 프로덕트.** Expo(React Native) 모바일 앱 — 구글맵 + 만보기 포인트 |
| [`web/`](web/) | 초기 웹 프로토타입 (Leaflet 기반, 참고용으로 보존) |

## 앱 핵심 기능

1. **구글맵 기반 지도** — 카테고리 이모지 아이콘 + 가격 배지 마커, 가격/카테고리 필터
2. **스팟 투고** — 지도 롱프레스로 1000엔 이하 가게 등록 (커뮤니티 게시판은 의도적으로 제외)
3. **가성비 투표** — 👍 コスパ良い / 👎 微妙
4. **만보기 포인트 「チリツモ」** — 1,000보마다 10pt, 1일 1만보 한도 + 로그인 보너스.
   일본에서 대중적인 **ポイ活**(트리마, aruku& 등 걷기 포인트 앱) 문화를 겨냥한 보급 전략.
5. **절약 가이드 (교육)** — 세금·연금·전기/가스/수도·통신비·주거·장학금 8개 카테고리,
   키워드 검색 가능. 기사마다 이해도 퀴즈가 있고 정답 시 +5pt (포인트 시스템과 연동).
6. **교환소 (B2C)** — 운영자 제공 쿠폰을 포인트로 교환 + 경품 추첨(チリツモ抽選).
   유저 간(C2C) 기프트권 매매는 사기·古物営業法 리스크로 **의도적으로 제공하지 않음**
   (거지맵과 동일한 설계 판단).
7. **리워드 허브** — 만보기 구간보상(1일 최대 40pt) + 출석·광고시청(재원 연동의 핵심,
   1일 최대 60pt)·룰렛·보물상자 타일. **포인트 수령·사용은 로그인(닉네임 등록) 필수**,
   구경·투고는 익명 가능 — 다계정 파밍 억제(거지맵 방식).

실행 방법과 상세 설계는 [`mobile/README.md`](mobile/README.md) 참고.
