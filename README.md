# ビンボーマップ (Binbo Map) 🍜

한국의 **거지맵**(1만원 이하 가성비 식당 공유 지도)을 일본 시장에 맞게 로컬라이징한 지도 서비스 MVP입니다.

> 일본판 컨셉: **"1000円以下のコスパ最強スポットをみんなで共有"** — 1000엔 이하로 한 끼를 해결할 수 있는 가게와 무료 스팟을 함께 모으는 지도.

## 데모 실행 방법

빌드 도구 없이 바로 실행됩니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages / Vercel / Netlify에 그대로 올려도 동작합니다 (정적 파일만 사용).

## 현재 구현된 기능 (MVP)

| 기능 | 거지맵 원본 | 이 MVP의 일본판 구현 |
|---|---|---|
| 가격 맞춤 검색 | 5,000~10,000원 슬라이더 (기본 7,000원) | **300~1,000엔 슬라이더 (기본 700엔)** + ワンコイン(500엔) 프리셋 |
| 지도 표시 | 전국 식당 지도 | Leaflet + OpenStreetMap (API 키 불필요), 도쿄 중심 샘플 데이터 15곳 |
| 카테고리 | 식당 위주 | 定食・食堂 / 麺類 / 丼・カレー / 弁当 / パン / **無料スポット** |
| 제보하기 | 상호명·가격·위치·후기 제출 → 승인 | 지도 클릭 → 투稿 폼 (1000엔 초과 입력 차단). MVP에서는 localStorage 저장 |
| 가성비 투표 | 가성비 올림/내림 | 👍 コスパ良い / 👎 微妙 (localStorage 저장) |

## 일본 로컬라이징 포인트

- **가격 기준**: 한국의 "1만원 이하" 대신 일본의 **ワンコイン(500엔) 런치 문화**와 "1000엔의 벽(1000円の壁)"을 기준선으로 사용.
- **네이밍**: 거지맵의 직역 「乞食マップ」는 일본어에서 차별적 어감이 강해 사용 불가. 자조적이면서 친근한 **「ビンボーマップ」(빈보=가난뱅이)** 채택. (일본의 「貧乏飯(빈보메시)」 밈과 연결됨)
- **무료 스팟 카테고리**: 거지맵의 "무료 공공시설" 개념을 도쿄도청 전망대, 皇居東御苑 같은 무료 명소로 확장.
- **UI 언어**: 서비스 UI는 전부 일본어.

## 파일 구조

```
index.html      # 화면 구조 (필터 사이드바 + 지도 + 투고 모달)
css/style.css   # 스타일 (모바일 대응 포함)
js/data.js      # 카테고리 정의 + 도쿄 샘플 스팟 15곳 (데모용 개략 좌표)
js/app.js       # 지도 렌더링, 가격/카테고리 필터, 제보, 투표 로직
```

## 프로덕션 로드맵 (다음 단계)

1. **백엔드 추가**: Supabase 또는 Firebase로 스팟/투표를 서버 저장 (현재는 localStorage → 본인 브라우저에만 보임). 익명 투고 + 관리자 승인 큐(거지맵도 승인제).
2. **지도 고도화**: 이용자가 많아지면 마커 클러스터링(`leaflet.markercluster`), 현재 위치 검색(Geolocation API), 지역별 데이터 분할 로딩.
3. **커뮤니티/핫딜 게시판**: 거지맵의 '거지방'·'핫딜'에 해당하는 節約板(절약 노하우)·特売情報(특가 정보) 추가.
4. **법적 검토(일본)**: 가게 후기·가격 정보는 명예훼손(名誉毀損)·신용훼손 리스크가 있으므로 신고/삭제 절차와 이용약관 필수. 위치정보·투고 데이터 처리는 個人情報保護法 준수.
5. **배포/확산**: 웹 우선(거지맵도 웹으로 바이럴) → PWA → 네이티브 앱. 확산 채널은 X(Twitter) 절약 계정, 5ch/なんJ계 밈 문화권이 유효.
